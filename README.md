# کافه معدن — نمونهٔ حرفه‌ای «نبض مالی معدن»

صفحهٔ فارسی و راست‌چین برای معرفی همایش هوش مالی در معدن‌داری. شروع صفحه از بخش پایانی ویدیوی معدن است: نورها لوگوی کافه معدن را شکل می‌دهند، لوگو به سمت بالای تصویر حرکت می‌کند و صحنه به سفیدی می‌رسد. بخش‌های روایت معدن و مالی، سخنرانان، شبیه‌ساز فرضی، محورهای همایش و دعوت پایانی بعد از آن باقی مانده‌اند.

## پیش‌نمایش مستقل

فایل `preview.html` را در Chrome یا Edge باز کنید. نیازی به نصب بسته ندارد. برای پخش ویدیوی اسکرول‌محور، فایل‌های `public/videos/mineral-film-edited-v3.mp4` و `public/images/logo-formation-poster.png` باید کنار پیش‌نمایش بمانند. ابتدای فیلم از حدود ۶۲٪ زمان آن رد می‌شود تا بخش کامیون نمایش داده نشود.

## اجرای React و Vite

پیش‌نیاز: Node.js نسخهٔ ۱۸ یا جدیدتر و دسترسی به npm برای دریافت وابستگی‌ها.

```bash
npm install
npm run dev
```

برای ساخت خروجی انتشار:

```bash
npm run build
npm run preview
```

## آنچه در نمونه هست

- شروع سینمایی کوتاه با نورها و تشکیل لوگو؛ ویدیو با اسکرول کنترل می‌شود و بخش کامیون از ابتدا حذف شده است.
- سه ایستگاه روایی برای ذخیره و عیار، اقتصاد استخراج، و جریان نقد و ریسک.
- معرفی سخنرانان با فضای آماده برای عکس، سوابق و ویدیوی دعوت نهایی.
- شبیه‌ساز سناریوی فرضی که قیمت فروش، هزینهٔ استخراج و سرمایهٔ اولیه را تغییر می‌دهد؛ درآمد، هزینه، سود عملیاتی و آزمون فشار را دوباره محاسبه می‌کند.
- بخش محورهای همایش و دعوت پایانی؛ تاریخ، مکان و ثبت‌نام تا زمان دریافت اطلاعات واقعی عمداً موقت مانده‌اند.

## فرض‌های شبیه‌ساز

حجم فروش سالانه ۱٫۲ میلیون تن و هزینهٔ ثابت سالانه ۱۸ میلیون دلار فرض شده است. آزمون فشار قیمت را ۱۵٪ پایین و هزینهٔ متغیر را ۱۰٪ بالا می‌برد. آستانهٔ سادهٔ قیمت، هزینهٔ ثابت را با بازیافت خطی سرمایهٔ اولیه طی پنج سال ترکیب می‌کند.

این محاسبه مالیات، بازیابی، زمان‌بندی پروژه، تأمین مالی، عیار محصول قابل‌فروش و نوسان واقعی بازار را لحاظ نمی‌کند. همهٔ اعداد نمونه فرضی‌اند و توصیهٔ سرمایه‌گذاری یا تحلیل یک معدن واقعی نیستند.

## پیش از انتشار

- تاریخ و محل برگزاری، محورهای نهایی، عنوان رسمی همایش و مسیر ثبت‌نام را جایگزین کنید.
- نام و سوابق سخنرانان را با اطلاعات تأییدشده کامل کنید و عکس‌ها و ویدیوهای اصلی را جایگزین نگه‌دارنده‌ها کنید.
- ویدیو را روی گوشی‌های هدف، سرعت اینترنت پایین و حالت کاهش حرکت مرور کنید.
